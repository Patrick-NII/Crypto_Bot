# Worklog - Journal de Travail

Ce dossier contient le journal de travail du projet GlueTrade Trading Platform.
Chaque entree documente le travail effectue, les bugs rencontres et corriges,
et fournit un resume clair pour la reprise du travail.

## Convention de nommage

```
YYYY-MM-DD_titre-court.md
```

## Structure d'une entree

```markdown
# [Date] - Titre

## Resume
Bref resume de ce qui a ete fait.

## Travail effectue
- Liste des taches completees

## Bugs rencontres et corriges
- Bug: description -> Fix: solution

## Prochaines etapes
- Ce qui reste a faire

## Notes de reprise
Ce qu'il faut savoir pour reprendre le travail.
```
